# UI幾何制約 & レスポンシブ仕様書

## 1. 幾何レイアウトの絶対規律（Inviolable Geometry Rules）
1. **図鑑コンテナの小窓スクロール禁止**:
   - `max-height` + `overflow: auto` / `overflow-y: scroll` による二重スクロール・小窓スクロールを完全禁止。
   - コンテンツ量に応じて外側ページ全体が自然にスクロールするナチュラルドキュメントフローを採用する。

2. **テキストの三点リーダー（...）省略禁止**:
   - 専門用語、筋名、神経支配、検査手技説明において `text-overflow: ellipsis` による文字切り捨てを禁止する。
   - 全ての臨床知識は全文が可読・表示されなければならない。

3. **スマホ画面幅（390px）はみ出しゼロ（Zero Horizontal Overflow）**:
   - ビューポート幅 390px（iPhone 12/13/14標準）において横スクロールバーの発生を物理的に根絶。
   - カード、テーブル、バッジの最小幅・マージン・パディングを緻密に調整し、100%完全収容する。

## 2. 視覚デザイン規律（Aesthetic Standards）
- **ベースカラー**: Warm Bone（`#F9F8F6`、上質な生成り・ミニマリスト・エディトリアル調）。
- **タイポグラフィ**: システムサンセリフ（`-apple-system, BlinkMacSystemFont, "Hiragino Sans", "Noto Sans JP", sans-serif`）。
- **カード表現**: 厚みのあるカルタ札のような立体感と手触り、スムーズなマイクロインタラクション。
