# ダニエルズ徒手筋力検査法（第10版）準拠 臨床仕様書

## 1. 臨床判定原則
1. **段階3（Grade 3）スタートの鉄則**:
   - 全ての筋力検査は、原則として「抗重力位での自力自動運動（段階3）」から開始する。
   - 段階3達成確認後、段階4（中等度の抵抗）、段階5（最大抵抗）へと段階的徒手抵抗を付加する。
   - 段階3未達成時は直ちに重力除去位（段階2）へ体位変換し、免荷支持下での可動域を評価する。

2. **質的評価語（Normal / Good / Fair / Poor / Trace / Zero）の廃止**:
   - ダニエルズ第10版の改訂に準拠し、曖昧な質的呼称を完全排除。
   - 数値グレード（Grade 5, 4, 3, 2, 1, 0）およびプラス/マイナス付加による定量的・客観的記録を徹底する。

3. **例外肢位・背臥位テストの臨床ルール**:
   - 腹臥位が取れない患者（心肺疾患、股関節屈曲拘縮、妊婦等）に対する修正肢位（背臥位テスト）の併記。
   - 股関節伸展（大臀筋）等の背臥位代替肢位における固定・抵抗ベクトルの厳格な幾何整合性。

## 2. 検査構成要素（Four Pillars of MMT）
- **肢位（Position）**: 被検者の初期姿勢、関節の中間位/基準アライメント。
- **固定（Stabilization）**: 代償動作（Trunk trick motion等）を防ぐための近位部固定部位。
- **抵抗（Resistance）**: てこの原理に基づく遠位部への適切な方向（重力・運動方向と逆向き）の徒手抵抗。
- **免荷・支持（Gravity-Minimized Support）**: Grade 2における摩擦軽減（パウダーボード、検者による四肢重量支持）。
